# Task 1: Linux Terminal Navigation & Environment Exploration

## Commands Practised
- pwd — Displays the full path of the current working directory.
- whoami — Displays the currently logged-in username.
- hostname — Displays the system's host name.
- date — Displays the current system date and time.
- ls, ls -l, ls -la — Lists directory contents with details and hidden files.
- cd, cd .., cd -, cd ~ — Navigates using relative paths, parent directory, previous directory, and home directory.
- mkdir -p — Creates nested project directories.
- touch — Creates empty files.
- find — Verifies the created folders and files.

## What I Learned
I learned how to check my current directory and user session, navigate the Linux filesystem using absolute and relative paths, and create and verify an organized directory structure from the terminal.
